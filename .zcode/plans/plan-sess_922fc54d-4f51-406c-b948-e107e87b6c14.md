## 5. Modal opens → page jumps to top

Root cause: antd Modal's scroll-locker sets `overflow:hidden` on `body`; because `html,body,#root{height:100%}` and body's overflow currently **propagates to the viewport**, locking body resets the propagated scroller → scrollTop clamps to 0.
- `global.css`: make the scroll own the `html` element explicitly — `html { overflow-x: clip; overflow-y: auto; }` (explicit html overflow ends body→viewport propagation, so the lock can't touch real scrolling), change `height:100%` to `#root { min-height:100% }` (html/body auto height).
- Verify with Playwright: scroll to Schedule section, open "New job" → `window.scrollY` unchanged; re-verify scroll-spy, rail deep-links and nav shrink still work after the CSS change.
